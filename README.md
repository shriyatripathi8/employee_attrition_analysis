# employee_attrition_analysis
Data analytics project showcasing  employee attrition analysis using python , SQL and power BI

Project Overview
This project analyzes employee attrition patterns using HR analytics data to identify key factors affecting employee turnover. The dashboard provides business insights into attrition trends across departments, salary ranges, job roles, gender, and employee experience.

The project demonstrates end-to-end analytics workflow using:
SQL
Excel
Power BI
Dashboard Preview

The dashboard includes:
Employee KPIs
Attrition analysis
Department-wise attrition
Salary-based attrition insights
Job role analysis
Gender analysis
Interactive slicers
Business Problem

Employee attrition impacts:
productivity
hiring costs
team performance
organizational stability

Objectives
Analyze employee attrition trends
Identify departments with high attrition
Understand salary impact on attrition
Generate actionable workforce insights

Dataset Information -Dataset used: IBM HR Analytics — Kaggle
Created derived columns:
Salary_Slab,Age_Group,Experience_Level,Attrition_Flag

Key Insights
Research & Development and HR departments show high attrition rates.
Employees aged 41–50 show higher attrition.
Higher salary groups still experience significant turnover.
Manager and HR-related job roles show elevated attrition.

Business Recommendations
1. Improve Employee Retention Programs
2. Reduce Overtime Dependency
3. Focus on Mid-Career Employees
4. Improve Job Satisfaction
5. Review compensation and workload policies
